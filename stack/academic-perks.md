# 🎓 Academic Perks & Student Benefits

> Leverage your `.edu` affiliation to access enterprise-grade tools at zero cost. This page expands on the toolkit overview with full setup instructions and hidden benefits.

---

## 1. Developer Infrastructure

### GitHub Student Developer Pack

The most valuable single benefit available to CS students. Activate at [education.github.com](https://education.github.com/).

**Included highlights:**

| Tool | Value | What It Gives You |
| :--- | :--- | :--- |
| **GitHub Copilot** | $10/month | AI pair-programmer in VS Code, JetBrains, Neovim |
| **GitHub Codespaces** | 180 core-hours/month | Cloud Linux dev environment, accessible from any browser |
| **GitHub Pro** | $4/month | Private repos, advanced insights, Pages for private repos |
| **DigitalOcean** | $200 credit | Droplets for hosting, CI runners, proxy servers |
| **Namecheap** | 1 year free `.me` domain | Personal website / portfolio domain |
| **1Password** | Free Teams account | Password manager for you and your lab |
| **Canva Pro** | Free | Poster design, presentation templates |
| **JetBrains All-Products Pack** | ~$700/year | PyCharm, CLion, IntelliJ, DataGrip, GoLand, etc. |

**Verification**: University email OR official enrollment document + ISIC card.

### JetBrains Student Pack

Activate separately at [jetbrains.com/community/education](https://www.jetbrains.com/community/education/).

Key IDEs for CS researchers:
- **PyCharm Professional** — Scientific mode, Jupyter integration, remote SSH interpreter
- **CLion** — C/C++ with CMake integration, perfect for HPC and systems work
- **DataGrip** — Multi-dialect SQL IDE for database-heavy research
- **IntelliJ IDEA** — Java/Kotlin/Scala for distributed systems research

## 3. Writing and Productivity

### Overleaf

The industry-standard collaborative LaTeX editor. Institutional access gives you:
- Unlimited collaborators per project
- Full Git synchronization (`git clone` your Overleaf projects)
- History and track changes
- Increased compile timeouts for complex documents

Check if your university has institutional Overleaf access: [overleaf.com/for/universities](https://www.overleaf.com/for/universities).

### Notion for Education

Upgrade to Plus Plan free with academic email. Use cases in research:
- **Lab wiki**: Shared knowledge base with nested pages
- **Paper tracker**: Relational database of papers, tags, status, and notes
- **Meeting notes**: Linked to action items and deadlines
- **Research roadmap**: Kanban or timeline views for project planning

### Grammarly Premium

Available for free at many institutions via site licenses. Check your university's software portal before paying.

## 4. Library and Journal Access

### Institutional Library Proxy

Set up your library's proxy server in your browser. Then any journal link automatically uses your institutional subscription:

```
# Example proxy prefix (check your library's actual URL)
https://your-library-proxy.example.edu/login?url=
```

**Browser extensions for seamless access:**
* **[Unpaywall](https://unpaywall.org/)** — Automatically finds legal open-access PDFs for paywalled papers.
* **[Open Access Button](https://openaccessbutton.org/)** — Finds free legal versions or requests papers from authors.
* **[Library Genesis Button](https://chrome.google.com/webstore/detail/libgen-button/)** — Direct LibGen search from any paper page.

### Key Databases Requiring Institutional Access

| Database | Content |
